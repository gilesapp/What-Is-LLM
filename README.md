
# Start 
## uv (https://docs.astral.sh/uv/guides/projects/)
#### installation 
- windows powershell `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`
- pip `pip install uv`
#### change your uv cache directory `[Environment]::SetEnvironmentVariable("UV_CACHE_DIR", "XX:\your-cache-dir", "User")`
